# User Stories

This directory contains user stories for this project.

## Organization

User stories can be organized in several ways:

### By Epic
```
user-stories/
├── epic-1-authentication.md
├── epic-2-product-browsing.md
└── epic-3-checkout.md
```

### By Individual Stories
```
user-stories/
├── US-001-user-login.md
├── US-002-password-reset.md
└── US-003-browse-products.md
```

### Mixed Approach
```
user-stories/
├── epic-1-authentication.md
├── US-001-user-login.md
├── US-002-password-reset.md
└── backlog.md
```

## Template

Use the [User Story Template](../../templates/User-Story-Template.md) for creating new user stories.

## Guidelines

- Each story should be independent
- Stories should be estimable (< 8 story points)
- Include clear acceptance criteria
- Link to related PRD sections
- Reference design mockups if available
